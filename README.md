# Calculator Using Java Swing (MVC Architecture)

A desktop calculator application developed using Java Swing and the Model–View–Controller (MVC) architecture. The project demonstrates basic arithmetic operations and separation of application logic from the user interface.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Graphical user interface
- Separate model and user interface logic using MVC architecture

## Technologies Used

- Java
- Java Swing
- AWT
- Model–View–Controller (MVC)
- JDK
- Visual Studio Code

## Prerequisites

- JDK installed
- Visual Studio Code or another Java IDE

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/anjuyadav21122006-crypto/Calculator-MVC.git
   ```

2. Open the project folder in Visual Studio Code.
3. Compile the Java files:

   ```bash
   javac *.java
   ```

4. Run the class containing the `main()` method:

   ```bash
   java CalculatorView
   ```

   Replace `CalculatorView` with the correct main class name in your project.

## MVC Architecture

- **Model:** Performs arithmetic calculations.
- **View:** Displays the calculator interface.
- **Controller:** Handles user interactions and connects the model with the view.
